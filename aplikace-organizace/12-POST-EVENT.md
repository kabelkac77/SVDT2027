# Post-event / uzavření ročníku

Post-event má tři fáze.

## 1. Bezprostředně po akci
Zone Manager zůstává, dokud není zóna fyzicky čistá. Musí vědět co se deinstaluje, co jde kam, do jaké dodávky a kdo to odváží. Zone Manager může sám označit zónu CLOSED.

Pokud něco chybí/je poškozené/nedořešené, může zónu uzavřít s výhradou. Povinná poznámka + viditelná výstraha do vyřešení. Detailní kusová inventura zatím mimo systém.

## 2. Následující dny/týdny
### Finance
Doplatky, faktury, plan vs actual, neuhrazené položky, finanční uzavření.

### Partners
Fulfillment, foto/video/URL důkazy, report, poděkování, feedback, poznámka pro další ročník.

### Media
Evidovat co mělo vzniknout, co bylo dodáno, kdo dodal a kde je finální archiv. Vazby na partner deliverables.

**Synology Drive (~6 TB)** je kandidát na hlavní media/file storage. Prověřit API a integrační model. App minimálně drží metadata, stav a odkazy.

## 3. Retrospektiva a archivace
Feedback pro každého člena crew, ridery, partnery, dodavatele a diváky. Systém/AI může tematicky seskupit odpovědi → lessons learned + backlog.

### Final Event Report
Návštěvnost, riders, finance, partner fulfillment, media outputs/dosahy, incidenty, personál, feedback, co fungovalo/nefungovalo, doporučení. Data srovnatelná mezi ročníky.

### Archive + Next Edition
Uzavřený ročník zamknout jako historii. Do dalšího ročníku selektivně převzít role/strukturu, zóny, checklisty, partnery/dodavatele jako kandidáty, šablony a lessons learned. Nepřenášet staré incidenty ani zaplacené faktury.
