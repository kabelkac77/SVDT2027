Odpovědnosti

Stránka se generuje ze souboru ZADANI.md příkazem npm run dashboard. Jiný zdroj stavu neexistuje — co není v zadání, není ani tady.

Sledovaný bod je řádek zadání se značkou K doplnění, K potvrzení nebo Rozpracováno, případně zodpovězený řádek se značkou ✔ a datem. Ukázková data ve zdrojových grafikách jsou fiktivní a nesmí se zaměnit za skutečné výsledky.

Zadání se od načtení této stránky změnilo.
