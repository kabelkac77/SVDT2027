# Místní kolektory — omezený implementační krok

Implementovat pouze `event-app/tools/backup-local.js`, ESM Node>=24 built-ins fs/path/child_process. Knihovna bez CLI/scheduleru/sítě/logování. Žádné závislosti ani přístup ke skutečným souborům v modelu. Host testuje syntetické soubory a SQLite. Vrací bajty pro stávající createBackup, nikoli tvrzení kompletní zálohy; PostgreSQL/Storage jsou další krok.

## Explicitní soubory

Export async `collectLocalFiles(root, paths, source)` -> Promise<pole `{source,path,bytes:Buffer}`>. source jen 'sources' nebo 'inputs'. paths neprázdné pole relativních POSIX cest, žádné globy/procházení rootu. Každou cestu předem ověřit: source prefix přidat až ve výsledku, max1000 znaků, žádný absolutní/drive/backslash/control/loneUTF16/./../prázdný segment; segment<=255UTF8. Duplicity včetně NFC+lowercase odmítnout. root existující skutečný adresář, poslední komponenta nesmí být symlink; pod rootem žádný symlink ani neadresář u mezisegmentů, na konci jen obyčejný soubor. Nečíst adresáře nebo speciální soubory. Pro zdroje i vstupy blokovat segmenty .git/.local/.next/node_modules/backups, .env* a přípony .key/.pem/.p12/.pfx. Žádné tiché vynechání. Limit10000souborů, součet128MiB. Otevřít O_RDONLY|O_NOFOLLOW; porovnat dev/ino před a po otevření, číst jen ověřený descriptor. Před/po čtení kontrola size/mtimeNs/ino, při změně chyba; vždy close. Nic ve zdrojích neměnit. Path výsledku `${source}/${originalRelativePath}`. bytes kopie. Chyba vždy Error('BACKUP_LOCAL_FAILED'), bez raw path/dat/OS chyby.

## Konzistentní SQLite crew a exporty

Export `collectCrewSnapshot({database,pythonExecutable,parent})` -> Promise<poleBackupFiles>. Všechny argumenty jsou absolutní cesty; Python exe musí existovat jako obyčejný spustitelný soubor (symlinky běžných exe lze vyřešit jednou realpath), database obyčejný soubor bez koncového symlinku. parent existující adresář pro nový mkdtemp '.svdt-collector-'0700. V něm JS vytvoří jediný `workspace.sqlite3` exkluzivně0600 a zapamatuje dev/ino. Žádné reálné soubory ve fixture/modelovém kontextu. Nepoužívat shell ani proměnné PYTHONPATH/secrets při subprocessu. Python spustit `pythonExecutable -I -c FIXED_SCRIPT`, parametry db/output přes JSON stdin, timeout60s, maxBuffer192MiB. Skript je součást knihovny, nikoli config/external executable text.

Python stdlib sqlite3: zdroj URI mode=ro, žádné vytvoření zdroje, snapshot přes Connection.backup do připraveného souboru, poté snapshot journal_mode=DELETE a PRAGMA integrity_check musí být jediný řádek 'ok'. Všechny čitelné běžné user tabulky ze sqlite_master type='table' AND name NOT LIKE 'sqlite_%'; schéma crew musí mít tables meta,history,categories,working,audit,requests (neprázdné initialized v meta, také potřebné sloupce níže; nepřijímej prázdnou libovolnou DB). Dotazovat pouze snapshot, tabulky/kolony korektně quotovat dvojitými uvozovkami, dynamický obsah není SQL. Bez načítání extensions nebo běhu uloženého SQL. Tabulky deterministicky podle názvu; neměnit zdroj ani zdrojové WAL/SHM.

Výstup crew/workspace.sqlite3; exports/crew-tables.json se všemi tabulkami `{name,columns,rows}` (NULL a integer zachovat; BLOB explicitně `{type:'blob',base64:...}`), exports/crew-table-0001.csv atd. UTF8 BOM CSV, hlavičky všechny původní sloupce, texty začínající po whitespace =,+,-,@,tab,CR chránit apostrofem pro Excel; NULL zůstává prázdný CSV a JSON je bezeztrátový doplněk. Tabulky obsahují i audit a všechny ročníky. exports/crew-export.json metadataverze1, tabulky/count/column names, žádné absolutní cesty nebo kontakty mimo vlastní datové exporty. Celý snapshot zavřít před čtením jeho bytes.

Privátní IPC: Python vrátí JSON `{files:[{source,path,base64}]}` pouze přes zachycenou pipe stdout; JS ji nikdy nevypisuje ani nepředává do logu. Stderr nikdy nezobrazovat. Není to veřejný CLI výstup. Node zkontroluje úspěšný exit, JSON, whitelist očekávaných cest/source, striktní Base64, součet128MiB/max10000 a důsledně vrátí Buffery. Žádný fallback při chybě/nedostupném Pythonu nebo špatné DB. Chyba opět jen BACKUP_LOCAL_FAILED.

finally odstraní pouze JS vytvořený snapshot pokud je stále stejný dev/ino, a vlastní nyní prázdný temp adresář. Žádné recursive rm nad přidanými cizími soubory. Zavřít všechny fd/SQLite spojení i při chybě. Skutečná data ani klíče nevypisovat. Zachovat stávající backup-bundle.js; žádné jiné soubory. Completed questions=[]; neblokující poznámky summary.

## Přesný model místního SQLite pro validaci

meta:key,value; history:id,year,content; categories:id,name,name_key,color,sort_order,version; working:id,year,category_id,content,source_id,version,updated_at; audit:id,at,kind,record_id,before_json,after_json; requests:id,fingerprint,response. Všechny tyto tabulky/sloupce jsou povinné, další tabulky/sloupce se také zálohují a exportují. meta.initialized musí být neprázdný text.

Navíc `exports/crew-working.csv` je lidský přehled řádků working a jejich JSON content: id,year,category (název z categories),name,position,owner,status,term,friday,saturday,email,phone,notes,estimate,agreed,total,paid,barter,merch. Obsah working.content musí být JSON objekt, money pokud přítomné objekt. Částky jsou uložené haléře, záhlaví označí haléře; žádné přepočítání NULL na0. Tento čitelný výběr nenahrazuje úplné tabulkové JSON/CSV, které zachovají i extra/zdrojová pole a historii. CSV chránit stejně proti Excel vzorcům. Konstantní očekávané cesty IPC zahrnují i crew-working.csv.
