# Organizační struktura SVDT 2027

## Vojta
- Race Coordinator / Race Control → starter, předřazení+rider logistics, timing
- Registrace + Rider Care
- Manažer traťových komisařů → 4–5 traťových manažerů zón → cca 30 pískačů
- Track Manager → logistika překážek, naskakovač, safety finishing, zábrany, repair team
- IZS Coordinator
- Broadcast Manager
- Internet
- Finance
- administrativa/povolení
- marketing/vizuál/merch
- Crew Base (?) — zařazení otevřené
- Vojta +1 — obsadit

## Vlasta
- Partnerships
- 3–4 Production Zone Managers
- Kids Race Manager
- VIP Manager
- Bar Manager
- Afterparty Manager
- Branding Lead
- hlavní elektrikář
- Info Point
- Press/Media
- Security
- Waste/Cleaning — doplnit managera
- Production/Logistics Lead — doplnit
- Radio Manager
- Back Office ×3 v týdnu před akcí
- Runner / člověk na autě
- Vlasta +1 — Jindra (?)

## Průřezově
- Světlana = manažerka komisařů + Crowd Lead.
- Runner v race day = společný mobilní zdroj.
- Instalaci a deinstalaci vlastní stejná větev.
