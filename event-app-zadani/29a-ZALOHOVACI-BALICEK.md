# Omezený krok: šifrovaný zálohovací balíček

Implementovat pouze event-app/tools/backup-bundle.js jako ESM knihovnu Node built-in fs/path/crypto/zlib, žádné závislosti, síť, CLI/scheduler nebo skutečné soubory uživatele. Žádný modelový přístup k soukromým datům. Aplikační kolektory budou další krok; tento modul netvrdí že umí stáhnout databázi nebo přílohy.

Export REQUIRED_SOURCES = ['sources','crew','inputs','postgres','storage','exports']. createBackup(files,sources,key) -> Buffer. files = pole {source:string,path:string,bytes:Buffer|Uint8Array}; path je relativní POSIX cesta obsahující jako první segment source. sources = právě jednou každý povinný zdroj {name,complete:true,fileCount:integer}; fileCount musí odpovídat skutečnému počtu files daného zdroje. Sources/crew/inputs/postgres/exports vyžadují aspoň jeden soubor, storage může být známě prázdné. Neúplný/missing/duplicitní/neznámý zdroj odmítnout. Každý soubor obsahuje v uloženém manifestu source,path,size,sha256,base64. Verze1 a createdAt ISO. Součet bytes max128MiB, max10000 souborů, cesty max1000 znaků. Žádné tiché vynechávání. Validovat i typy/deskriptory, ne jen truthy hodnoty.

Cesty: žádná absolutní cesta, drive prefix, backslash, NUL/control, prázdný segment, . nebo ..; musí začínat přesně source+'/'. Odmítnout duplicitní cesty i NFC+lowercase aliasy kvůli přenositelné obnově. Zachovat původní text platné cesty. Nezpracovávat žádné symlinky nebo vstupní odkazy (files jsou bajty, žádné čtení cizího filesystemu). Prototypové názvy nebrat jako objektové klíče (Map/Set).

Kryptografie Node crypto AES-256-GCM, náhodný12b nonce, 16b tag, klíč přesně32 bajtů Buffer/Uint8Array. MAGIC ASCII 'SVDTBACKUP1\n', buffer formát MAGIC + nonce + encrypted(gzip(JSON payload)) + tag; MAGIC+nonce použít jako AAD. Nikdy neukládat klíč, nepoužívat heslo přímo jako AES klíč, žádné vlastní kryptografické primitivy. gzip před šifrováním, gunzip s maxOutputLength192MiB. createBackup je jediný producent tohoto formátu.

readBackup(bundle,key) -> {version:1,createdAt,sources,files} se soubory obsahujícími source,path,bytes (Buffer). Nejprve ověřit GCM tag, až potom dekomprimovat a parsovat. Potom znovu validovat úplnost, všechny cesty, velikosti, striktní validní Base64, SHA256 a všechny limity před jakýmkoliv filesystem zápisem. Chyby vždy konstantní Error('Záložní balíček není platný nebo jej nelze bezpečně zpracovat.'), bez dat/path/klíče nebo raw crypto chyby.

writeBackupExclusive(target,bundle): parent už musí existovat, uvnitř něj náhodný dočasný soubor0600, fsync a publikace přes link bez přepsání; při chybě odstranit jen vlastní temp. Existující target/symlink zachovat a odmítnout. Žádné vytváření/přepis cizích adresářů nebo mazání existujících vadných souborů. Metoda nemá klíč a pouze ukládá předané šifrované bajty.

restoreBackupExclusive(target,bundle,key) -> {files:number}: nejprve úplný readBackup, pak vytvořit nový target0700 (existující včetně symlinku odmítnout), adresáře0700 a soubory0600 přes exkluzivní vytvoření. Nikdy nepřepsat existující cíl, žádné extrakční shell příkazy, spouštění kódu nebo změna běžící DB. Při chybě odstranit pouze tento nově vytvořený vlastní target, nikoliv cizí obsah; odmítnutí existujícího cíle ho musí nechat byte-for-byte. Validaci GCM/manifestu provést před vytvořením targetu. Bez stdout/logu/tajných hodnot. Host testuje reálnou kryptografii, poškození, cesty, úplnost a obnovu na fiktivních bajtech.
